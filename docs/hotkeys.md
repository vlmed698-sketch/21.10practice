# ГОРЯЧИЕ КЛАВИШИ ДЛЯ РАБОТЫ С ОКНАМИ (KDE Plasma)

```text
Win  — клавиша с логотипом Windows (между Ctrl и Alt)
Ё    — клавиша слева от «1», над Tab
+    — нажимать одновременно
Стрелки — ← → ↑ ↓
```

## ПЕРЕКЛЮЧЕНИЕ МЕЖДУ ОКНАМИ

```text
Alt + Tab               следующее окно (держите Alt, жмите Tab)
Alt + Shift + Tab       предыдущее окно
Win + Tab               то же, что Alt + Tab
Alt + Ё                 следующее окно того же приложения
Win + Alt + стрелка     перейти к окну слева / справа / сверху / снизу
Win + Ctrl + A          перейти к окну, которое «мигает» и просит внимания
```

## УПРАВЛЕНИЕ ОКНОМ

```text
Alt + F4                закрыть окно
Win + Page Up           развернуть на весь экран
Win + Page Down         свернуть в док
Win + Backspace         вернуть прежний размер
Win + ←                 прикрепить к левой половине экрана
Win + →                 прикрепить к правой половине экрана
Win + ↑                 прикрепить к верхней половине экрана
Win + ↓                 прикрепить к нижней половине экрана
Win + Shift + ← / →     перенести окно на другой монитор
Alt + F3                меню окна (поверх всех, на все столы и т.д.)
Win + Ctrl + Esc        убить зависшее окно: курсор станет черепом —
                        кликните по окну (Esc — отмена)
```

## МЫШЬЮ

```text
Win + перетаскивание левой кнопкой    двигать окно за любое место
Win + перетаскивание правой кнопкой   менять размер окна
Двойной клик по заголовку             развернуть / восстановить
Красная / жёлтая / зелёная кнопка     закрыть / свернуть / развернуть
  (в левом верхнем углу окна, как в macOS)
```

## ОБЗОР ОКОН (как Mission Control)

```text
Win + W                 обзор: все окна и рабочие столы
Win + G                 все рабочие столы сеткой
Win + F9  (или Ctrl + F9)    все окна текущего рабочего стола
Win + F10 (или Ctrl + F10)   все окна со всех рабочих столов
Win + F7  (или Ctrl + F7)    все окна текущего приложения
Win + D                 показать рабочий стол (ещё раз — вернуть окна)
```

## РАБОЧИЕ СТОЛЫ

```text
Win + Ctrl + ← / →             переключиться на соседний рабочий стол
Win + Ctrl + Shift + ← / →     перенести окно на соседний рабочий стол
Ctrl + F1 … F4 (или Win + F1 … F4)   перейти на рабочий стол 1–4
(Сейчас рабочий стол один — добавить можно в «Параметры системы →
 Окна → Виртуальные рабочие столы».)
```

## ЗАПОМИНАНИЕ ПОЗИЦИЙ ОКОН (скрипт rememberwindowpositions)

```text
Win + X                 временно не восстанавливать позиции окон
Win + Ctrl + W          настройки скрипта
```

## ПОИСК (как Spotlight)

```text
Win + Пробел            поиск приложений, файлов, калькулятор
                        (заработает после перезахода в сеанс)
Alt + Пробел            то же самое (работает уже сейчас)
```

## ДОК (Crystal Dock)

```text
Наведите мышь — иконки увеличиваются, как на Mac.
Правый клик по доку     настройки дока, закрепить / открепить приложение
Win + Shift + L         Launchpad — все приложения сеткой (или значок в доке)
```

## ПРОЧЕЕ

```text
Alt + F1 (или просто Win)   меню приложений
Alt + Tab               переключение окон «карточками» (Cover Flow)


Изменить любое сочетание: Параметры системы → Клавиатура →
Комбинации клавиш → KWin.
```
